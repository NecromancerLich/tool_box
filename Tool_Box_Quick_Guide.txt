TOOL_BOX v0.29 - QUICK GUIDE
============================

Tool_Box is a Bash-based, menu-driven security lab and network utility wrapper.
It is intended for systems, networks, and accounts you are authorized to test or administer.

STARTING TOOL_BOX
-----------------
Make the script executable and launch it as your normal desktop user:

    chmod +x tool_box_v0.29.sh
    ./tool_box_v0.29.sh

Use the built-in privilege menu or sudo prompts when a task requires root access.
Running the entire program as root is not required for normal use.

GLOBAL NAVIGATION FOOTER
------------------------
Nested menus display:

    [0] Back   [M] Main Menu   [T] Set Target/Data   [W] Workspace   [H] Help

Shortcuts:
0  Go back one menu level.
M  Return directly to the Main Menu.
T  Jump to Set Target / Data, then return to Main Menu.
W  Jump to Workspace / Project, then return to Main Menu.
H  Open Quick Help / Workflow Guide, then return to Main Menu.

The Main Menu shows only T, W, and H because Back/Main Menu are unnecessary there.
Using these shortcuts does not discard the active target, ports, settings, output
folder, privilege state, or loaded workspace.

TARGET & SCANNING
-----------------
Workspace / Project
    - Create and load named projects.
    - Save current target, subnet, ports, wordlist, threads, and output settings.
    - Maintain timestamped notes and structured findings.
    - Import Nmap XML, grepable (.gnmap), and normal text results.
    - Store imported services in services.tsv.
    - Show service-aware recommendations.
    - Archive or delete a workspace with safeguards.

Set Target / Data
    - Set IPv4 address.
    - Set subnet /1 through /32.
    - Set individual ports, ranges, or lists.
    - Set the output folder.

Scan Profiles
    - Quick Recon
    - Full TCP Recon
    - Web Server
    - Windows / SMB
    - Linux Server
    - Custom Nmap builder

Nmap Builder
    - SYN, Connect, or UDP scan type.
    - Version, OS, default scripts, skip ping, T4, and aggressive toggles.
    - Custom options.
    - Optional timestamped output.
    - Command preview before execution.

CUSTOM TARGET / QUERY OVERRIDES
-------------------------------
Several tools can use temporary values without changing the global Tool_Box target:

DNS Lookup       Custom hostname or DNS name
Reverse DNS      Custom IP address
WHOIS            Custom IP address or domain
Traceroute       Custom IP address or domain
Netcat TCP Test  Custom IP/domain and port

WHOIS, Traceroute, and Netcat provide a reset option to return to the current
global target. These temporary values are useful for quick lookups while keeping a
TryHackMe or other lab host set as the main target.

PRIVILEGE GUIDANCE
------------------
[USER]
Most web, DNS, SMB client, service-enumeration, text-processing, reporting,
and utility actions.

[ROOT OPTIONAL]
Some Nmap scan modes can benefit from raw-socket privileges/capabilities.

[ROOT REQUIRED]
Packet capture, some ARP/network discovery operations, and package/repository changes.

RECOMMENDED WORKFLOW
--------------------
1. Create or load a Workspace.
2. Set the target, subnet, ports, output path, wordlist, and threads.
3. Run an Nmap scan/profile.
4. Import saved Nmap output into the workspace when useful.
5. Review service-aware recommendations.
6. Enumerate the discovered Web, SMB, DNS, or other services.
7. Record important information in Notes and Findings.
8. Search/compare results and generate a Markdown report.
9. Archive the target or workspace when finished.

NAVIGATION TIP
--------------
You rarely need to climb all the way back through the menu tree in v0.29.
Use M for Main Menu, T for target settings, W for workspaces, and H for help.
